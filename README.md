# PRISTINE — PEACE ON PEAKS

A cinematic, tourism-focused mock website for **PRISTINE Restaurant**, a hilltop destination near Margalla Hills, Islamabad.

## Demo

This is a static HTML/CSS/JS demo built for presentation purposes. All images are sourced from Unsplash as placeholders.

## Sections

1. **The Journey Begins** — Mountain views, clouds, sunrise, sunset, moon & stars
2. **Discover PRISTINE** — English garden, koi pond, nature walks, photography, butterflies
3. **Experiences & Adventures** — Swings, vintage Cessna, bonfire, music, dance, fireworks, camping, bikers
4. **Taste & Togetherness** — Live BBQ, fine dining, tea, family gatherings, events, décor
5. **Voices & Visitor Stories** — Testimonials and visitor-submitted content
6. **Visit Us** — Location, reservations, social links, Google Maps

## Features

- Fully responsive (mobile, tablet, desktop)
- Smooth scroll-triggered animations
- Fixed navigation with blur backdrop on scroll
- Mobile hamburger menu
- WhatsApp & phone reservation links
- Embedded Google Maps
- Premium dark aesthetic with gold accents

## How to Use

1. Open `index.html` in any modern browser.
2. Or serve with a static server:
   ```bash
   npx serve .
   # or
   python3 -m http.server 8000
   ```

## Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Push these files to the `main` branch.
3. Go to **Settings → Pages** and set source to `main` / `root`.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
